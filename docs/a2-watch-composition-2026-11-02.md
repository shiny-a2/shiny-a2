# A clearer A2 Watch landing

Release 3.23.0 gives the Persian and English A2 Watch landing an open introduction and a full-width pinned watch scene. Decorative floating panels no longer cover the watch; existing vector artwork, scroll-controlled motion, captions and the pause control remain.

Three business entry paths lead directly to storefront, customer follow-up and repair capabilities. Each opens its existing module and moves keyboard focus to the summary. The fifteen-module catalogue, capability selection, contact brief and delivery evidence retain their existing owners. Roles and references receive a calmer layout without adding new delivery or performance claims.

Local Chromium and WebKit checks each passed eight language, width and theme contexts for layout, interactive contrast, selected capabilities, theme switching and menu escape. Eight Chromium journey checks covered pinned positioning, scroll progress, pause behavior and keyboard shortcuts. Reduced-motion and no-JavaScript reading passed at 320px. Content and canonical-URL checks pass. Physical-device performance remains unmeasured.

This is a Watch-specific composition update. The rest of the product family remains scheduled for individual review; the retained reference homepage assets are not claimed as original A2 artwork.

Release 3.23.0 is live. Changed and new runtime files match the release through HTTPS. Live Chromium journey and interactive/contrast checks each passed all eight language, width and theme combinations, including reduced-motion and no-JavaScript reading.
