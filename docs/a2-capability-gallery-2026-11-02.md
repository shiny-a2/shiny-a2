# A2 capability gallery — 3.5.0

All twelve A2 product landings now let visitors explore three capabilities in a visual gallery before reading the complete module list. The gallery uses actual module titles, descriptions and features from the product content. Conceptual interface frames clarify the scope without presenting customer screenshots or invented transactions and metrics.

Native radio controls support pointer, keyboard and no-JavaScript selection. Motion is limited to a short pointer-triggered frame transition; keyboard and reduced-motion reading remain steady. Each gallery links to its full module disclosure, including direct-fragment reload. Section navigation highlights the part of the page being read without changing focus or the URL. Existing canonical URLs, bilingual alternatives and the cinematic scroll experience remain intact.

Local checks passed 96 gallery contexts in Chromium and 96 in WebKit across twelve products, English/Persian, mobile/desktop and light/dark appearance. Final focused checks passed sixteen contexts per browser with active section navigation, direct-module links and reading fallbacks. Both next-product routes and reversal cancellation passed. Content and link checks cover all 24 canonical landings, while sitemap validation remains at 315 canonical URLs. Physical-device performance and owner visual acceptance are not claimed.
