# Readable A2 project briefs — 3.9.0

When a visitor selects several capabilities, the contact page now presents them as a readable list rather than a single comma-separated paragraph. Clearing the choices restores the existing explanatory empty state.

Short guidance helps visitors describe the problem they want to solve and their current tools. Optional fields are explicitly labeled. A description containing only spaces cannot generate a draft; typing a meaningful description clears the error. The message draft separates each section label from its content and expands within a bounded reading area, with scrolling for longer requirements.

The existing selection and contact flow is retained. No new form fields were added, and the page does not automatically send a message. Chromium and WebKit each pass eight local Persian/English, mobile/desktop and light/dark contexts, including selection-list parity, empty state, whitespace validation and recovery, transfer and draft invalidation. Canonical-page checks retain 315 sitemap URLs. Selection and draft states were visually reviewed. Email delivery, conversion gains and owner acceptance are not claimed.
