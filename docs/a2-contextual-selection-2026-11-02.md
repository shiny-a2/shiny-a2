# A2 contextual capability selection — 3.8.0

Visitors can now choose a capability while reading its expanded description. The control stays inside the open module, keeping the collapsed product overview uncluttered. A selection count and review link lead to the existing project brief, where visitors can adjust their choices before preparing a message.

Selections stay synchronized in both directions: changing the brief updates the module control, and resetting choices clears both. Native toggle buttons expose their selected state to assistive technology. The review link opens the picker and moves keyboard focus to its summary. Without JavaScript, module content and direct contact remain available.

Local Chromium and WebKit checks pass eight Persian/English, mobile/desktop and light/dark combinations per browser. They cover keyboard selection, synchronization, reset, focus, contact and language transfer, input validation, draft invalidation and no-JavaScript fallback. Static checks match every control to its product module across all 24 canonical landings and retain 315 canonical sitemap URLs. Active controls were visually inspected in both appearances and viewport sizes. No actual message was sent; no conversion uplift or owner acceptance is claimed.
