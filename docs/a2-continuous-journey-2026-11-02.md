# A continuous A2 homepage and products journey

Release 3.21.0 connects the homepage and products in a repeatable scroll journey. Reaching the end of the homepage continues into products; reaching the end of products returns to the homepage opening. The browser retains its rendering canvas, while the address, page metadata and navigation update to the active page. Browser Back and Forward follow that journey. Other pages and language changes remain ordinary navigations.

The opening mark now reads A2. Persian and English closing invitations keep their words intact, avoiding the duplicated and clipped text produced by the previous character animation. Footer columns adapt to mobile and desktop, and closing areas use the shared light and dark palette. The return-to-start control also supports keyboard activation.

Local validation covers both languages and themes at mobile and desktop widths in Chromium, English continuity in WebKit, in-session theme changes, language switching, opening-canvas behavior, reduced-motion and no-JavaScript fallbacks, direct contact anchors and keyboard return to the start. The content and indexability checks pass. Physical-device performance has not been measured.

Release 3.21.0 is live. Live continuity and browser-history checks passed four Persian Chromium and four English WebKit viewport/theme combinations. The changed runtime files match the published release. Live closing-section checks passed in both languages at mobile and desktop widths, including in-session light/dark switching and language navigation.

The retained reference scene assets remain credited and are not presented as original A2 artwork. About, Contact and product-detail redesigns remain separate stages.
