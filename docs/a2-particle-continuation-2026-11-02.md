# A2 particle-scene continuation

Continuing to the next page from the cinematic homepage previously opened a text-only A2 introduction. The About destination now includes the reference particle cloud, suspended rocks, terrain and camera movement before the A2 story and career timeline. Forward and reverse scrolling drive the scene; a skip link takes readers directly to the editorial.

The composition uses A2 branding and the existing bilingual content source. It does not initialize the reference studio's team portraits, client logos or awards. The retained Lusion scene is credited and is not represented as original A2 artwork. The scene reuses model and texture files already hosted with the reference capture; these assets load when the scene initializes.

Persian copy retains RTL shaping while the scene uses its original coordinates. The preceding layout correction also keeps homepage narrative text clear of the astronaut viewport. Editorial supports light and dark appearance; reduced-motion readers receive the same information without the WebGL timeline.

Local checks passed eight language, viewport and appearance combinations in each of Chromium and WebKit. They cover camera progression and reversal, skip navigation, menu interaction, reading fallback, overflow and load errors. Actual wheel continuation from the homepage reached the scene in both languages. Content and canonical-indexability checks passed. Cold-load testing also exposed an absolute startup deadline that could hide a scene while loading still progressed. The adapter now detects stalled progress instead; deterministic checks cover active loading for two minutes, successful completion and a single reading fallback after a stall. Release 3.19.1 is published. Live checks pass all four Persian mobile/desktop and light/dark combinations in Chromium and WebKit. Native end-scroll navigation reaches the active scene in both languages. Published scene and editorial frames were visually inspected, and changed runtime files match the release hashes.
